# Markdown File

Nella cartella `Models/ORM` sono presenti i modelli ORM (Object-Relational Mapping) utilizzati per interagire con il database. Questi modelli rappresentano le tabelle del database come classi C#, consentendo di eseguire operazioni CRUD (Create, Read, Update, Delete) in modo più intuitivo e orientato agli oggetti.
Inserire sottocartelle per organizzare i modelli in base alla fonte dati, per esempio `Models/ORM/Database1`, `Models/ORM/Database2`, ecc. In questo modo, sarà più facile gestire e mantenere i modelli in progetti di grandi dimensioni con più fonti dati.
