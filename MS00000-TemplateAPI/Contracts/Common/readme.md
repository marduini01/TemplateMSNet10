# Markdown File

Questa cartella contiene i modelli di contratto comuni utilizzati in tutto il progetto. I modelli di contratto definiscono le strutture dei dati che vengono scambiate tra il client e il server tramite le API. 
Questi modelli possono includere entità, DTO (Data Transfer Object) e altre strutture dati necessarie per rappresentare le informazioni in modo coerente e standardizzato.
