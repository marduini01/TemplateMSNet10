# Markdown File

La cartella "Application/Business Services" contiene i servizi di business utilizzati per implementare la logica di business dell'applicazione. 
Questi servizi orchestrano le operazioni tra i modelli, i repository e altri componenti dell'applicazione, garantendo che le regole di business siano rispettate.
Questa tipologia di service non accede mai su database, verso altre API esterne ma si occupa di orchestrare le operazioni tra i vari componenti dell'applicazione, come i modelli, i repository e altri servizi.
