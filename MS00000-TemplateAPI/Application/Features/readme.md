# Markdown File

La cartella "Application/Features" contiene le funzionalità dell'applicazione, organizzate in feature specifiche. Ogni feature rappresenta un'unità di funzionalità dell'applicazione e può includere comandi, query, handler e altri componenti necessari per implementare la logica della feature.
Definire per ogni funzionelità una sua cartella dedicata, in cui inserire i comandi, le query e gli handler associati a quella specifica funzionalità. 
Questo approccio favorisce la modularità e la manutenibilità del codice, consentendo di isolare le diverse funzionalità dell'applicazione e facilitando la comprensione del flusso logico.
